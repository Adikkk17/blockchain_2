# 📰 Crypto News Aggregator

**Crypto News Aggregator** — это веб-приложение на Rust, которое позволяет пользователям получать последние новости и информацию о криптовалютах по их символам (например, BTC, ETH, DOGE). Данные автоматически собираются из публичных API и визуализируются в виде интерактивной HTML-страницы.

---

## 🔍 Описание проекта

Приложение реализует агрегатор криптовалютных новостей, который:

- подключается к **CoinPaprika API** для получения описания криптовалюты;
- использует **GNews API** для извлечения новостных статей;
- визуализирует полученную информацию на веб-странице с использованием HTML-шаблонов `Tera`.
